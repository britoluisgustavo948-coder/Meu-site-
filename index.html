Sobre o projeto

A ideia é transformar o computador em uma ferramenta de aprendizado, criação e desenvolvimento profissional.

🎯 Meu objetivo

Desenvolver habilidades práticas em tecnologia e criar projetos que possam futuramente gerar oportunidades profissionais e fontes de renda.

💡 Minha estratégia

Estudar, praticar, construir projetos reais, criar um portfólio e utilizar os conhecimentos adquiridos para oferecer soluções para outras pessoas e empresas.

Plano de aprendizado

Quatro áreas principais para construir uma base sólida em tecnologia.

AI

Inteligência Artificial

Aprender fundamentos de IA, ferramentas, automações e criação de soluções inteligentes.

PY

Python

Construir uma base de programação e desenvolver pequenos sistemas, automações e ferramentas.

WEB

Desenvolvimento Web

Aprender HTML, CSS e JavaScript para criar sites modernos, responsivos e funcionais.

3D

Impressão 3D

Aprender modelagem, preparação de arquivos e desenvolvimento de produtos personalizados.
